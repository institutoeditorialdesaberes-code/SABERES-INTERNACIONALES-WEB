Conectar con GitHub

Este panel guarda los cambios directamente en tu repositorio. Cada vez que guardas, Cloudflare Pages reconstruye el sitio solo, en menos de un minuto.

Cómo obtener tu token (una sola vez):
  1. Entra a github.com → Fine-grained tokens.
  2. En Repository access elige Only select repositories y marca tu repositorio del sitio.
  3. En Permissions → Repository permissions, pon Contents: Read and write. Nada más.
  4. Genera el token y pégalo aquí abajo.

Se guarda solo en este navegador y en este equipo. No se envía a ningún otro servidor. Si usas una computadora compartida, pulsa «Salir» al terminar.

Se completa solo desde site.config.json. Cámbialo aquí si aún no lo has actualizado.
